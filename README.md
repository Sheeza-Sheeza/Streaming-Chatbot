# Streaming Chatbot Demo

## What is Streaming?

Streaming in chatbots refers to sending responses gradually, token by token (like words or characters), instead of all at once. This creates a "typing" effect, making the conversation feel more natural and responsive, similar to how ChatGPT displays responses.

## How the Chatbot Works

1. The backend is built with Python and FastAPI, using WebSockets for real-time communication.
2. When you send a message, the backend receives it via WebSocket.
3. The backend streams responses from GPT-4o by sending each token (part of a word) as it's generated by the model.
4. The frontend receives each token and appends it to the chat area live, creating the streaming effect.

## Steps to Run

### Backend
1. Navigate to the `backend` folder:
   ```
   cd backend
   ```
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Run the server:
   ```
   uvicorn main:app --reload
   ```
   The backend will start on `http://localhost:8000`.

### Frontend
1. Serve the frontend from a local HTTP server to avoid CORS issues:
   ```
   cd frontend
   python -m http.server 3000
   ```
2. Open `http://localhost:3000/index.html` in your web browser.
3. Type a message and click "Send".
4. Watch the bot's response appear in real-time!

## Upgraded to GPT-4o Streaming

This version now uses OpenAI's GPT-4o model with real streaming.

### How GPT-4o Streaming Works

- The OpenAI API supports streaming responses, where the model generates tokens (subword units) one by one as it thinks.
- Each token is sent immediately over the WebSocket to the frontend without waiting for the full response.
- This creates the live typing effect as the AI generates the response in real-time, just like ChatGPT.

### Setting Up the API Key

1. Get an OpenAI API key from https://platform.openai.com/api-keys
2. Set the environment variable before running the backend:
   - On Linux/Mac: `export OPENAI_API_KEY=your_api_key_here`
   - On Windows: `set OPENAI_API_KEY=your_api_key_here`
   - Or use your system's environment variable settings

Make sure the API key is set before starting the backend server.
